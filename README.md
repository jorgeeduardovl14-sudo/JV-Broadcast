# JV Broadcast V16.4 Firebase

Actualización puntual basada en V16.2.

## Cambios
- Al avanzar de set, el resultado actual se guarda y queda visible junto al marcador.
- El nuevo set empieza automáticamente en 0–0.
- Botón **Corregir último set** para restaurar el último resultado guardado.
- Textos editables para Próximamente, Partido, Tiempo técnico, Entre sets y Final.
- Se mantienen Firebase, QR, patrocinadores, cintillos, escenas, YouTube y control remoto.

## Despliegue
Sube el ZIP completo en Netlify > Deploys. Cierra y vuelve a abrir las páginas en ambos dispositivos para evitar caché anterior.
